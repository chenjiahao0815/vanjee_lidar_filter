技术方案

照 cloud_passthrough_filter.cpp 的骨架写，不另起一套。新节点 VanjeeVoxelFilterNode，放在同一个包里。

订阅万集点云，裁立方体，切小体素，删竖直方向没厚度的格子，发过滤后的点云。

---

直接复用现成的东西

内存池 PointCloudMemoryPool         原样搬过来，acquire / release 不动
日志限频 PT_INFO / PT_WARN          连同 shouldFrameLog、updateFrameLogGate、cloud_log_interval_sec 一起搬
参数装载 declare_and_load_parameters   同样的写法，构造函数里读一次存成员
启动打印 log_startup                 把算出来的体素边长和门槛也打出来，现场好对账
发布封装 publish_cloud
去非法点 removeNonFinitePointsInPlace

立方体裁剪不用自己写。passthrough_filter_cpu 就是干这个的，按 x y z 三轴各调一次，limit 用 box 的上下限。filter_order、enable_x/y/z、debug 分轴话题这套全都能用。

点类型跟着现有的用 pcl::PointXYZ。ring 和 intensity 会丢，但判删只看 z，用不上；现有直通节点本来也是这么丢的，保持一致。

---

新写的部分

体素结构
  struct Voxel { uint32_t count; float zmin, zmax; std::vector<uint32_t> idx; bool keep; }
  std::unordered_map<int64_t, Voxel> grid_    成员变量，每帧 clear 复用，构造时 reserve

buildVoxelSizeTable()
  构造函数里调一次，把边长和门槛算死，回调只查表。
  基础边长照 vertical_column_xy_voxels 的路子写成整数倍：边长 = base × N，N 按距离取。
  近档代表距离 r_max/2，远档 r_max。每档算：
    line_gap = r × ang_v      上下两条扫描线的间距
    pt_gap   = r × ang_h      同一条线上相邻两点的间距
    size_z   = min(base_z  × ceil(line_gap / base_z),  max_z)
    size_xy  = min(base_xy × ceil(pt_gap   / base_xy), max_xy)
    thr_z    = line_gap × thr_ratio
  两条硬约束，不满足就抬参数打 warn：
    size_z >= 2 × line_gap    装不下两条线的话墙上每格也只有一条线，全判成平的，会全删
    thr_z  <  size_z          门槛比格子还高的话跨度永远够不着，等于一个都不删

  距离放大也可以照 yaml 里现成的写法：scale_distance_threshold 加 slope，
  effective = base × (1 + slope × (r - scale_dist))，跟地面分割那套保持一个风格。

buildVoxelGrid(cloud)
  第一遍扫点，只装格不判。
  r = hypot(x, y) 选档，ix = floor(x × inv_xy)，iy 同理，iz = floor(z × inv_z)，必须 std::floor。
  key 压成 int64：档号 2 位 + ix/iy/iz 各 20 位，负数加偏移转非负。
  档号必须进 key，两档边长不同，不带档号 3m 和 7m 的格子会撞在一起。
  更新 count、zmin、zmax，push 下标。空格子不建项。

markFlatVoxels()
  第二遍，遍历 grid_ 打标记，不动点。
  span = zmax - zmin，keep = span >= 该档 thr_z。
  count==1 时 span 是 0，自然被删。

extractByFlag(cloud, want_keep)
  第三遍，从内存池 acquire 一块，按标记把点 push 进去返回。
  传 true 出保留点，传 false 出被删点，debug 复用同一个函数。

cloud_callback
  照现有回调的结构：updateFrameLogGate → acquire → fromROSMsg → removeNonFinite
  → 三轴 passthrough 裁立方体（每轴 debug 可发）
  → grid_.clear() → buildVoxelGrid → markFlatVoxels
  → extractByFlag(true) 发 output_topic
  → debug_mode 时 extractByFlag(false) 发 removed_topic
  → release，打耗时

---

边界

框的长宽高一般除不尽边长，边上剩不满一格的薄片，点少、z 跨度天然小，会被误删，在框边留一圈缺口。
算索引时把最后一格范围放宽，余量并进相邻的最后一整格，不单独成格。
两档的分界距离取成该档边长的整数倍位置，让交界落在格线上。

参数，照 ground_segmentation.yaml 的风格写在节点名下

input_topic / output_topic / removed_topic
debug_mode / cloud_log_interval_sec / use_sim_time
memory_pool_size / memory_pool_reserve
filter_order / enable_x / enable_y / enable_z / limit_min_* / limit_max_*    立方体
ang_h / ang_v / r_max                                                       角分辨率，弧度
base_xy / base_z / max_xy / max_z                                           体素边长
thr_ratio                                                                   门槛占线间距的比例，默认 0.5
